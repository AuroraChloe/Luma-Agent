# Scene Material Rules

- Derive the minimum number of distinct settings from the confirmed script.
- A scene asset is a stable environment reference, not a poster, a storyboard, or a beauty shot.
- Scene images must not contain characters, faces, readable text, watermarks, frame borders, or shot numbers.
- Preserve fixed geography, important props, lighting sources, palette, atmosphere, and available blocking space.
- Reuse one scene asset for consecutive beats in the same place. Split only when the setting or its state changes materially.
- Do not draft new story events or alter confirmed script facts.
