# Video Keyframe Material

## Purpose

Turn the confirmed concept script into one complete production storyboard sheet for a later reference-to-video stage. It contains a chronological panel for each immutable script beat, but remains one image asset. It is not a new script, a subject design sheet, a poster, or a finished video.

## Entry Gate

Do not plan or generate keyframes until every subject required by the confirmed concept has one explicitly approved production asset. Never use an unapproved draft, preview, older version, or unrelated chat image as a keyframe reference.

## Script Integrity

- Treat every confirmed beat's time range, purpose, content, and visual description as read-only facts.
- Produce exactly one panel direction for every confirmed beat, preserving source order.
- Never omit, merge, split, reorder, rewrite, or extend beats.
- Never add a character, location, prop, action, event, outcome, or relationship that is absent from the source beat.
- Director choices may control only how the existing beat is framed: shot size, camera angle, composition, visible action state, environment state, lighting, and continuity.

## Subject References

- Refer only to the approved subject catalog supplied at runtime.
- Include every approved subject explicitly named in the source beat.
- Include an environment or object subject only when it is visibly required by that beat.
- Keep each subject's identity and design stable across all panels.
- Do not infer a new subject merely because the script uses a generic noun or pronoun.

## Image Requirements

- Generate one complete multi-panel storyboard sheet with 9 to 15 cinematic panels selected by action complexity. A broad script beat may be expanded into its setup, motion, reaction, impact, and result moments without adding a new story event.
- Use the approved subject images as visual references, not as layouts to copy.
- Preserve identity, silhouette, face or surface, costume or material, palette, and signature details.
- Choose an action state that can naturally continue into motion in the later image-to-video stage.
- Keep spatial relationships, screen direction, visual state, and action handoff understandable between adjacent panels. Each panel must be a readable moment of continuous motion, not a repeated static scene.
- The sheet may use only small panel numbers and narrow gutters. Do not invent captions, shot labels, timecodes, watermarks, or explanatory text. When the source beat explicitly requires an overlay, preserve a suitable composition-safe area without rewriting the requested text.

## Review Boundary

The generated storyboard sheet is the single visual blueprint for the later video-generation stage. Vision reviews it together with the original concept and writes the one final video-model prompt. Show the storyboard sheet and that prompt to the user before any video task is submitted.

- If the user gives a concrete storyboard change, edit the existing complete sheet while preserving all unmentioned story facts, then rerun visual QA and prompt writing.
- Only explicit approval of both the sheet and prompt unlocks final video submission.
- This workflow never submits a video-model task before that approval.
